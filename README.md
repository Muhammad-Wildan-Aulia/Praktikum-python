# Praktikum Python

Proyek sederhana untuk latihan dasar pemrogramam Python, penggunaan *virtual environment*, pengelolaan dependensi, serta integrasi kontrol versi dengan Git.

 Program utama (`Halo.py`) menerima input tahun lahir pengguna, menangani kesalahan input menggunakan `try/except`, dan menghitung perkiraan usia secara otomatis berdasarkan tahun berjalan.
